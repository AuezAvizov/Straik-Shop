**Strikeshop** — это полнофункциональная e-commerce платформа на стеке PHP/MySQL, специально адаптированная под специфику страйкбольного снаряжения. Система объединяет в себе интуитивный интерфейс для игроков и мощный бэкенд для управления арсеналом магазина.

---

## Основной функционал

### Клиентская часть (Storefront)
* **Интерактивный каталог:** Продуманная сетка товаров с поддержкой категорий (Приводы, Снаряжение, Тюнинг).
* **Умные фильтры:** Поиск по калибру, бренду, ценовому диапазону и типу (AEG/GBB/Spring).
* **Динамическая корзина:** Управление покупками без перезагрузки страниц (AJAX).
* **Оформление заказа:** Простая и надежная форма сбора данных для доставки и выбора способа оплаты.

### Панель администратора (Command Center)
* **Inventory Control:** Управление товарными запасами, добавление новых лотов и редактирование характеристик.
* **Order Tracking:** Централизованная система мониторинга заказов и изменения их статусов в реальном времени.
* **User Management:** Контроль уровней доступа и ведение базы клиентов.
* **Analytics:** Базовая отчетность по популярным товарам и выручке.
